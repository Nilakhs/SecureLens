# 🔒 SecureLens

## AI Powered Secure Code Review Platform

SecureLens is an AI-powered secure code review platform that helps developers identify vulnerabilities, understand security issues, and improve code quality. Users can upload projects or connect GitHub repositories to automatically scan their code, receive AI-generated explanations, secure fix suggestions, and downloadable reports.

---

## 🎯 Goal

The primary goal of SecureLens is to:

- Scan uploaded software projects
- Detect security vulnerabilities
- Explain vulnerabilities using AI
- Suggest secure code fixes
- Generate detailed security reports
- Recommend code optimizations
